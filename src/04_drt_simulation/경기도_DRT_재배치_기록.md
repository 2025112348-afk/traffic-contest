# 경기도 DRT 재배치 시뮬레이션 — 과정 기록

"샌드박스 임의배치 267대" vs "이동격차지수 기준 재배치 267대" 비교. 코드는 같은 폴더의 `gyeonggi_reallocation.py`.

## 1. 왜 경기도인가

전국 DRT는 농어촌·인구감소 등 이동격차지수에 들어가는 변수와 어느 정도 연결된 사유로 도입된 곳이 많다. 반면 경기도 똑버스는 상당수가 **규제샌드박스**(임시 시범사업) 명목으로 도입되어, 실제 배치가 이동격차지수가 측정하는 취약성(지형장벽·의료·버스정류장·배차간격·고령인구비율·자가용미보유)과 거의 무관하게 결정된 경우가 많다. 즉 "총 운행대수는 정해져 있는데 배치 기준이 지수와 무관한" 깨끗한 사례라서, **"같은 267대를 지수 기준으로 재배치하면 어떻게 달라지는가"**를 보는 시뮬레이션 대상으로 적합하다고 판단했다.

## 2. 데이터 소스 선정 — 두 후보 비교

경기도 현재 배치를 읍면동 단위로 귀속시키려면 "운행구역 → 읍면동" 대응표가 필요했다. 두 후보가 있었다.

| | 가연 `경기도_경계기준_DRT비교.csv` | 은규 `경기도_DRT_종합.xlsx`(318행 전국본 기반) |
|---|---|---|
| 작성 방식 | admdongkor 602개 경계와 운행구역 명칭을 정확히 대조, "확인/미확인/기록없음" 3단계로 명시 구분 | 전국 318행 DRT 데이터셋에서 느슨한 문자열 매칭으로 추출 |
| 특례시 처리 | sggnm에 하위구 포함(예: "고양시일산동구") — 정확 | 시군구 컬럼에 하위구 누락(예: "고양시"만) — 매칭 오류 유발 |
| 결과 | 53개 "확인" 항목 | 24개 "유니크" 항목처럼 보였지만 실제로는 14개가 특례시 표기 누락으로 인한 가연 자료와의 **중복** |

남은 10개를 admdongkor 602개 실제 행정동 목록과 하나씩 직접 대조한 결과:

- **실존 확인 → 채택 (2건)**: 평택시 고덕동(고덕국제신도시), 파주시 교하동(운정신도시·교하지구) — 318행 데이터셋에 뉴스 출처도 있어 신뢰도 있음.
- **admdongkor에 없는 표기 → 기각 (7건)**: 고양시 덕은동·향동동, 안산시 목내동·성곡동·원시동, 안양시 안양9동(안양시만안구는 안양1~7동까지만 존재), 의정부시 민락동.

**결론: 가연 자료가 더 엄밀했고, 은규 자료에서 검증 가능한 2건만 보강 → 최종 55개 확인 읍면동.** 이것이 "55개 기준으로 다시 돌려줘" 요청의 근거다.

## 3. 현재 배치(샌드박스) 귀속 방법

- 공식 운행대수는 `data/raw/경기도_똑버스_운행현황.csv`(46개 운행구역 + 계, 합계 267대로 검증됨).
- 55개 확인 읍면동 각각에 대해, 그 읍면동이 속한 운행구역의 운행대수를 가져온다.
- 한 운행구역이 여러 읍면동에 걸치는 경우(예: 안성시 양성면이 "서부권"·"북부권" 두 구역에 모두 포함) `" / "`로 분리해 각 구역별로 처리하고, 한 읍면동이 여러 구역에 속하면 합산한다.
- 한 운행구역에 여러 읍면동이 확인된 경우, 그 구역 운행대수를 확인된 읍면동 수로 **균등 배분**한다(가연의 원칙 "차량수는 운행권역당 한 번만 저장"을 유지하면서 읍면동 단위로 내려보내기 위한 가장 보수적인 가정).
- 결과: 55개 확인 읍면동 중 운행대수를 귀속시킬 수 있었던 것은 **172대/267대(64.4%)** — 나머지 95대(35.6%)는 "운행구역에 읍면동 미명시" 또는 "해당 시군 기록 없음"으로 분류된 구역에 속해 읍면동 단위로 내려보낼 수 없었다.

## 4. 재배치 방법 — 최대잉여법(Largest Remainder Method)

### 4.1 왜 이 방법인가

사용자가 제기한 질문: "이동격차지수가 0.4인 지역과 0.18인 지역이면 버스 대수를 4:1로 할지 4:2로 할지 고민된다." 단순 비율(4:1 또는 4:2를 임의로 고르는 것)은 "총 대수가 정수여야 한다"는 제약과 "가능한 한 원래 비율에 가깝게"라는 목표를 동시에 만족시키지 못한다. 이를 수학적으로 정식화하면:

**정수계획 모형**
- 결정변수: $x_i \in \mathbb{Z}_{\ge 0}$ (읍면동 $i$에 배정할 DRT 대수)
- 제약: $\sum_i x_i = N$ (총 대수 고정, 여기서는 267)
- 목적: $\min \sum_i \left(x_i - N\cdot\dfrac{a_i}{\sum_j a_j}\right)^2$ (이상적 실수 비례 배분과의 편차 최소화), $a_i$=이동격차지수

이 문제의 정확해를 구하는 표준 알고리즘이 **최대잉여법**(선거 의석배분에서 쓰는 Hamilton/Largest Remainder 방법)이다.

### 4.2 알고리즘

1. 이상적 실수 몫 계산: $\text{share}_i = a_i / \sum_j a_j \times N$
2. 내림(floor)한 정수를 먼저 배정: $\lfloor \text{share}_i \rfloor$
3. 아직 배정되지 않은 나머지 대수만큼, 소수점 잉여($\text{share}_i - \lfloor \text{share}_i \rfloor$)가 큰 읍면동부터 1대씩 추가 배정

### 4.3 예시 계산 (사용자가 제기한 0.4 vs 0.18, N=6)

$\text{share}_{0.4} = 0.4/0.58 \times 6 = 4.138$, $\text{share}_{0.18} = 0.18/0.58 \times 6 = 1.862$
→ 내림: 4, 1 (5대 배정, 1대 남음) → 잉여: 0.138 vs 0.862 → 잉여가 큰 0.18 쪽에 1대 추가
→ **최종 배분 = 4 : 2** (4:1이 아니다)

코드: `gyeonggi_reallocation.py`의 `largest_remainder()`.

## 7. 한계

- 55개 확인 읍면동 중 운행대수를 귀속시킬 수 있었던 것은 172대(64.4%)뿐이고, 나머지 95대는 "운행구역에 읍면동 미명시" 상태라 읍면동 단위 비교에서 빠져 있다 — 과잉배치 의심 목록은 **이 95대를 포함하지 않은 하한선**으로 봐야 한다.
- 현재 배치 귀속 시 "운행구역 내 균등 배분" 가정을 썼다 — 실제로는 구역 내에서도 차량이 특정 읍면동에 더 집중될 수 있다.
- 재배치 결과는 이동격차지수 하나만 보고 배분한 것이라, 실제 도입 시에는 도로 인프라·운행 가능 거리 등 운영적 제약을 추가로 검토해야 한다.
