# 경기도 DRT 재배치 시뮬레이션 — 과정 기록

"경기교통공사 공식 임의배치" vs "이동격차지수 기준 재배치" 비교. 코드는 같은 폴더의 `gyeonggi_reallocation.py`. 이 문서는 v1(267대, 가연 제공 매핑 기반)과 v2(312대, 경기교통공사 공식 사이트 기반) 과정을 모두 남긴다 — 현재 유효한 버전은 **v2**다.

## 1. 왜 경기도인가

전국 DRT는 농어촌·인구감소 등 이동격차지수에 들어가는 변수와 어느 정도 연결된 사유로 도입된 곳이 많다. 반면 경기도 똑버스는 상당수가 **규제샌드박스**(임시 시범사업) 명목으로 도입되어, 실제 배치가 이동격차지수가 측정하는 취약성(지형장벽·의료·버스정류장·배차간격·고령인구비율·자가용미보유)과 거의 무관하게 결정된 경우가 많다. 즉 "총 운행대수는 정해져 있는데 배치 기준이 지수와 무관한" 깨끗한 사례라서, **"같은 대수를 지수 기준으로 재배치하면 어떻게 달라지는가"**를 보는 시뮬레이션 대상으로 적합하다고 판단했다.

## 2. v1 — 가연 매핑 + 267대 공식표 (2026-10-09, 폐기됨)

### 2.1 데이터 소스 선정 — 두 후보 비교

경기도 현재 배치를 읍면동 단위로 귀속시키려면 "운행구역 → 읍면동" 대응표가 필요했다. 두 후보가 있었다.

| | 가연 `경기도_경계기준_DRT비교.csv` | 은규 `경기도_DRT_종합.xlsx`(318행 전국본 기반) |
|---|---|---|
| 작성 방식 | admdongkor 602개 경계와 운행구역 명칭을 정확히 대조, "확인/미확인/기록없음" 3단계로 명시 구분 | 전국 318행 DRT 데이터셋에서 느슨한 문자열 매칭으로 추출 |
| 특례시 처리 | sggnm에 하위구 포함(예: "고양시일산동구") — 정확 | 시군구 컬럼에 하위구 누락(예: "고양시"만) — 매칭 오류 유발 |
| 결과 | 53개 "확인" 항목 | 24개 "유니크" 항목처럼 보였지만 실제로는 14개가 특례시 표기 누락으로 인한 가연 자료와의 **중복** |

남은 10개를 admdongkor 602개 실제 행정동 목록과 하나씩 직접 대조해 2건만 보강(평택시 고덕동, 파주시 교하동), 7건은 기각(고양 덕은동·향동동, 안산 목내동·성곡동·원시동, 안양 안양9동, 의정부 민락동) → **최종 55개 확인 읍면동**으로 v1 시뮬레이션을 돌렸다.

### 2.2 v1 결과 (폐기됨, 기록용)

- 공식 운행대수: `data/raw/경기도_똑버스_운행현황.csv`(46개 운행구역, 19개 시군, 합계 267대).
- 55개 확인 읍면동 중 **172대/267대(64.4%)**만 귀속 가능 — 나머지 95대는 "운행구역에 읍면동 미명시"로 분류돼 읍면동 단위 귀속 불가.
- 262개 읍면동이 재배치에서 1대 이상 배정(최대잉여법).
- 과잉배치 의심 12개, 신규후보 219개.

### 2.3 v1이 폐기된 이유

사용자가 똑타 앱(경기교통공사 통합교통플랫폼) 스크린샷 29장을 제공하면서, 앱의 "실시간 호출" 목록에 **267대 표에 없던 운행구역이 다수 확인됨**(광명 일직동·소하2동, 시흥 신천동·매화동, 수원 권선동, 이천 마장면·신둔면, 용인 모현읍, 화성 향남읍·팔탄면·봉담읍, 광주 탄벌동·장지동 등). 대조 결과 267대 표는 **2025년 중반 스냅샷**으로 추정되었고(의정부 개통 전 상태), 실제로는 2026년 1월 기사 기준 "20개 시군 311대"까지 늘어나 있었다. 다만 똑타 앱 자체에는 **운행대수가 전혀 표시되지 않아**(승객용 호출 앱이라 운영 정보 없음), 구역 목록만 최신화하고 대수는 못 채우는 상태였다.

이후 사용자가 **경기교통공사 공식 사이트**(gtrans.or.kr의 "시군별 버스대수" 페이지)를 찾아 34장 스크린샷으로 전체 자료를 제공 — 시군별로 운행구역·운행대수·운행차량(차종)까지 전부 나와 있는 **1차 공식 소스**였다. 이를 기준으로 v2를 다시 만들었다.

## 3. v2 — 경기교통공사 공식 자료 (2026-10-10, 현재 유효)

### 3.1 데이터

- 출처: `https://www.gtrans.or.kr/web/lay1/program/S1T499C698/ddock_bus/list.do` ("시군별 버스대수"), 2026-10-10 캡처.
- 저장 위치: `data/raw/경기교통공사_똑버스_운행현황_20261010.csv`.
- **21개 시군, 60개 운행구역, 총 312대** (이천시내권 캡처 누락 — 확보되면 총량 갱신 필요).
- 이천시내권을 제외한 312대가 2026년 1월 뉴스 보도치(311대)와 거의 일치해, 자료가 실제로 최신 시점을 반영한다는 교차검증이 됐다.
- DRT가 전혀 없는 것으로 확인된 10개 시군(성남·동두천·과천·구리·남양주·오산·포천·가평·양평·군포): 남양주는 2023년 사업 참여 철회가 뉴스로 확인됨, 과천은 2022년 "콜버스" 시범만 있었음, 나머지는 자료상 전혀 등장하지 않음.

### 3.2 운행구역 → 읍면동 매핑 (3단계 신뢰도)

v1과 마찬가지로 602개 admdongkor 행정동 경계(가연 `경기도_경계기준_DRT비교.csv`)를 기준으로, 운행구역명의 각 토큰을 대조했다. 결과를 3단계로 나눠 `gyeonggi_reallocation.py`의 `ZONE_MAPPING`에 그대로 기록했다:

- **확인** (41개 구역, 186대): 운행구역명의 각 토큰이 602개 행정동과 정확히 1:1 일치. 예: "고강본동,고강1동" → 고강본동 + 고강1동.
- **후보** (14개 구역, 100대): 신도시·통합권역명이라 여러 읍면동에 걸쳐 있어, 해당 대수를 후보 읍면동에 **균등분배**로 추정. 예: "동탄신도시" 20대 → 동탄1~9동에 각 2.22대. 가연의 `경계변환_결과.md`에 이미 정리돼 있던 9개 "추가 확인 필요" 구역(운정신도시·교하지구, 고덕국제신도시, 덕은동, 동탄신도시, 옥정신도시·삼숭동·회천지구, 백석읍·광적면·양주역, 은현·남면·덕정역, 민락1지구, 민락2·고산지구)의 후보 목록을 그대로 이어받았고, v2에서 새로 나온 권선동·당수동·고색오목천평리·초평동·향남지구·탄벌동장지동도 같은 방식으로 추정했다.
- **미확인** (5개 구역, 26대): 근거 부족으로 귀속하지 않음 — 고양시 고봉동·식사동·향동동(admdongkor 602개 목록에 해당 명칭 없음), 광주시 태전동·고산동(법정동으로 추정되나 상위 행정동 미상), 안산시 스마트허브(반월/시화공단 권역, 특정 행정동 특정 불가).

검증: 매칭된 읍면동 전부가 602개 경계 목록에 실존하는지 `gyeonggi_reallocation.py` 실행 시 자동 검증한다(불일치 시 에러 출력).

### 3.3 귀속 결과

**286대/312대(91.7%)가 읍면동 단위로 귀속**, 귀속된 읍면동 97개 — v1(172대/267대, 64.4%, 55개 읍면동)보다 범위·신뢰도 모두 크게 개선됐다.

## 4. 재배치 방법 — 최대잉여법(Largest Remainder Method)

v1과 동일한 방법, 총량만 N=312로 바뀌었다.

### 4.1 왜 이 방법인가

사용자가 제기한 질문: "이동격차지수가 0.4인 지역과 0.18인 지역이면 버스 대수를 4:1로 할지 4:2로 할지 고민된다." 단순 비율(4:1 또는 4:2를 임의로 고르는 것)은 "총 대수가 정수여야 한다"는 제약과 "가능한 한 원래 비율에 가깝게"라는 목표를 동시에 만족시키지 못한다. 이를 수학적으로 정식화하면:

**정수계획 모형**
- 결정변수: $x_i \in \mathbb{Z}_{\ge 0}$ (읍면동 $i$에 배정할 DRT 대수)
- 제약: $\sum_i x_i = N$ (총 대수 고정)
- 목적: $\min \sum_i \left(x_i - N\cdot\dfrac{a_i}{\sum_j a_j}\right)^2$ (이상적 실수 비례 배분과의 편차 최소화), $a_i$=이동격차지수

이 문제의 정확해를 구하는 표준 알고리즘이 **최대잉여법**(선거 의석배분에서 쓰는 Hamilton/Largest Remainder 방법)이다.

### 4.2 알고리즘

1. 이상적 실수 몫 계산: $\text{share}_i = a_i / \sum_j a_j \times N$
2. 내림(floor)한 정수를 먼저 배정: $\lfloor \text{share}_i \rfloor$
3. 아직 배정되지 않은 나머지 대수만큼, 소수점 잉여($\text{share}_i - \lfloor \text{share}_i \rfloor$)가 큰 읍면동부터 1대씩 추가 배정

### 4.3 예시 계산 (사용자가 제기한 0.4 vs 0.18, N=6)

$\text{share}_{0.4} = 0.4/0.58 \times 6 = 4.138$, $\text{share}_{0.18} = 0.18/0.58 \times 6 = 1.862$
→ 내림: 4, 1 (5대 배정, 1대 남음) → 잉여: 0.138 vs 0.862 → 잉여가 큰 0.18 쪽에 1대 추가
→ **최종 배분 = 4 : 2** (4:1이 아니다)

코드: `gyeonggi_reallocation.py`의 `largest_remainder()`.

## 6. 한계

- "후보" 신뢰도 14개 구역(100대)은 **신도시/통합권역 전체 대수를 소속 읍면동에 균등분배한 추정치**다 — 실제로는 특정 동에 더 집중돼 있을 수 있다(예: 동탄신도시 20대를 동탄1~9동에 단순 n분의 1 한 것).
- "미확인" 5개 구역(26대, 고양 고봉동·식사동·향동동, 광주 태전동·고산동, 안산 스마트허브)은 아예 귀속하지 않아, 과잉배치 의심 목록이 **이 26대를 포함하지 않은 하한선**이다.
- 이천시내권(옛 12대 규모) 스크린샷이 누락돼 총량(312대)에 미포함 — 확보되는 대로 갱신 필요.
- 재배치 결과는 이동격차지수 하나만 보고 배분한 것이라, 실제 도입 시에는 도로 인프라·운행 가능 거리 등 운영적 제약을 추가로 검토해야 한다.
