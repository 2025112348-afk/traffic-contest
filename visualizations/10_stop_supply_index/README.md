# 10번: 행정동별 인구 대비 버스 정류장 공급

![행정동별 공급](stop_supply_map.png)

`per10k = stops / population * 10000`. 14번과 공통 키인 `dong_code` 및 시도(`province`), 시군구(`sigungu`), 행정동(`dong`)을 포함한다.

2026-07-01 경계의 3,558개 행정동에 2025년 3월 버스 정류장을 집계했다. 2025년 인구 원본에는 시군구·코드가 없어 시도·동명이 양쪽에서 유일한 지역만 연결했다. 기존 3,044개와 시도명 정규화로 추가 연결한 368개, 총 3,412개가 매칭됐다. 공식 코드 매칭이나 기준시점 경계 일치가 검증된 것은 아니다.

시도명 정규화 이후에도 인구를 확정하지 못한 146개(동명 중복 136개, 미대응 10개)는 인구·고령화율·인구 대비 공급량을 결측으로 유지했다. `population_status`, `population_source_line`, `population_source_province`에서 매칭 근거와 원래 시도명을 확인할 수 있다. 결측을 인구 0으로 해석하지 않는다.

정류장 213,625개 중 213,476개가 공간 매칭됐다. 정류장 없는 행정동 13개도 유지한다. 지도 회색은 산출 불가, 색상 범위는 2~98 백분위다. 지표는 배차·보행거리·수요를 반영하지 않는다.
