# 14번: 행정동별 평일 버스 공급량

![행정동별 공급](dong_supply_map.png)

`departures_per_stop = departures / stops`. 예전 `per_10k`는 인구 1만 명당 값이 아니므로 이름을 수정했다. `headway_min`은 결측을 제외한 정류장별 배차간격의 단순 평균이다.

## 인구 대비 지표

10번과 동일한 `dong_code`로 인구를 연결해 다음 두 열을 추가했다.

| 열 | 계산식 | 의미 |
|---|---|---|
| `departures_per_10k_population` | `departures / population * 10000` | 인구 1만 명당 평일 정류장 운행횟수 |
| `headway_min_per_10k_population` | `headway_min / population * 10000` | 인구 1만 명 기준으로 나눈 평균 배차간격 |

계산 근거인 `population`, `population_year`, `population_status`도 포함한다. 인구 미매칭 146개 지역은 두 지표 모두 결측으로 유지하며, 인구가 0일 때도 나누지 않는다. 배차간격 자체가 결측이면 두 번째 지표도 결측이다. 두 번째 값은 실제 배차간격이나 승객 대기시간이 아니며, 동일 배차간격에서도 인구가 클수록 작아지는 산술 지표다.

10번과 동일한 2026-07-01 경계 3,558개 행정동을 사용한다. 공통 키는 `dong_code`이며 시도(`province`), 시군구(`sigungu`), 행정동(`dong`)을 포함한다. 지도는 해당 행정동 폴리곤으로 그린다.

2025년 3월 원본 운행 자료에서 버스 대상 정류장 213,625개만 사용했다. 배차간격 결측 4,456개도 운행량에 포함했다. 공간 매칭 213,476개, 평일 운행량 합계 18,544,545회다. 경계 밖 149개와 운행량 3,653회는 감사 자료에 기록했다.

정류장이 없는 행정동 13개는 정류장 수·운행량 0, 정류장당 공급량 결측이다. 지도 회색은 산출 불가, 색상 범위는 2~98 백분위다. 동일 차량은 여러 정류장에서 집계되므로 운행량 합계는 차량 수·좌석 수가 아니다. 경계와 운행 자료의 기준시점이 다르다.
