# 이동격차 지수 기반 DRT·마을버스 우선배치

「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」 제출용 저장소입니다.

## 한 줄 요약

공공데이터를 결합해 읍면동/리 단위 **이동격차지수**를 산출하고, 지수 상위 지역을 대상으로 DRT·마을버스 우선 배치 시나리오와 탄소감축 효과를 함께 제시합니다.

## 문제의식

국토교통부 DRT 도입·운영 가이드라인의 대상 기준은 정성적이어서, 전국 단위로 "어느 마을이 더 급한가"를 비교할 객관적 잣대가 없습니다. 국토연구원이 제안한 교통포용지수 개념은 있었지만 실제 자원 배분(DRT 배치)과 전국 단위로 연동된 적은 없습니다. 이 프로젝트는 기존 공공데이터를 결합해 시군구보다 세밀한 마을 단위까지 지수를 내려보고, 이를 DRT 차량 배치라는 실행 단위와 직접 연결합니다. 배경과 설계 전체는 [`docs/분석기획서.md`](docs/분석기획서.md)에 정리되어 있습니다.

## 저장소 구조

```
.
├── docs/                  분석기획서, 방법론 문서
├── data/
│   ├── raw/               원본 데이터 (용량/라이선스 문제로 git에 미포함, data/README.md 참고)
│   └── processed/         지표 계산용으로 정제된 데이터셋
├── src/
│   ├── 01_collect/        원자료 수집 스크립트
│   ├── 02_preprocess/     행정구역코드-존코드 매칭, 결측 처리
│   ├── 03_index/          4개 하위지표 계산 + 표준화 + 가중합 + 민감도분석
│   ├── 04_drt_simulation/ 우선권역 재군집화, 차량 대수 추정
│   ├── 05_carbon/         탄소감축 효과 3단계 계산
│   └── 06_visualize/      GIS 지도, 차트 생성
└── outputs/
    ├── figures/           최종 지도·차트
    └── tables/             최종 지수 테이블(csv)
```

## 데이터 출처

| 구분 | 데이터셋 | 제공처 |
|---|---|---|
| 공급공백 | 농림어업총조사 마을조사표 (대중교통 접근성 문항) | 통계청 KOSIS / MDIS |
| 수요밀도 | 가구통행실태조사 O/D, 생활이동데이터 | 국가교통DB(KTDB), data.molit.go.kr |
| 취약계층 | 고령인구·1인가구 비율 | 통계청 인구총조사(KOSIS) |
| 지형장벽 | 수치표고모델(DEM), 경사도 | 국토지리정보원, 국가공간정보포털 |
| 검증(탄소) | 지역별·차종별 도로부문 온실가스 배출량 | 한국교통안전공단(공공데이터포털) |

세부 다운로드 방법과 이용 신청 절차는 [`data/README.md`](data/README.md)에 정리되어 있습니다.

## 실행 방법

```bash
pip install -r requirements.txt

python src/01_collect/*.py       # 원자료 수집
python src/02_preprocess/*.py    # 행정구역 매칭·정제
python src/03_index/*.py         # 이동격차지수 산출
python src/04_drt_simulation/*.py
python src/05_carbon/*.py
python src/06_visualize/*.py
```
