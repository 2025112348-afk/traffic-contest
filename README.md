# 이동격차지수 기반 수요응답형교통(DRT) 재배치

「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」 제출용 저장소입니다.

## 한 줄 요약

공공데이터를 결합해 **읍면동 단위 이동격차지수**(버스접근성·인구취약성·의료접근성·지형장벽 4축, 6개 변수 엔트로피 가중)를 산출하고, 경기도 DRT(수요응답형교통) 재배치 시뮬레이션과 직접 연결해 재배치 후 취약지역의 이동격차지수가 실제로 낮아지는지 검증합니다.

## 분석 배경 및 목적

수송부문 온실가스 배출량의 약 97%가 도로교통에서 발생해 탄소중립을 위한 교통체계 개선이 시급하지만, 대중교통이 부족한 지역의 이동격차 문제는 여전히 존재합니다. 이를 해소할 정책 수단으로 수요응답형교통(DRT)이 거론되지만, 국토교통부 「DRT 도입·운영 가이드라인」의 기준은 "인구감소·고령화로 노선버스가 축소된 지역"처럼 정성적이어서, 어느 지역이 더 시급한지 비교할 전국 단위 객관적 기준은 비어 있습니다.

이 프로젝트는 기존 공공데이터를 결합해 읍면동 단위 이동격차지수를 산출하고, 이를 경기도 DRT 재배치 시뮬레이션과 직접 연결해 실제로 취약 지역의 이동격차지수가 낮아지는지 확인하는 것을 목표로 합니다.

## 분석 과정 및 방법

이동격차지수는 버스접근성·인구취약성·의료접근성·지형장벽 4개 축, 6개 변수(정류장 공급·배차간격·1인당 자동차 등록대수·고령인구비율·의료접근성·지형장벽)를 min-max 정규화 후 엔트로피 가중합으로 통합합니다. 경기도 DRT 재배치 시뮬레이션은 경기교통공사 공식 운행현황(326대)을 읍면동 단위로 귀속시킨 뒤, 같은 326대를 이동격차지수 비례로 최대잉여법을 적용해 재분배합니다. 전체 과정·수치·근거는 최종 분석보고서(hwp)와 각 폴더의 README/결과정리.md에 정리되어 있습니다.

## 실행 방법

```bash
pip install -r requirements.txt
# 지형장벽(경사도) 계산에는 GDAL 커맨드라인 도구(gdaldem)가 별도로 필요합니다 (예: apt install gdal-bin).

python src/01_collect/*.py                                      # 원자료 수집
python src/02_preprocess/*.py                                    # 행정구역 매칭·정제
jupyter nbconvert --execute 이동격차지수_3차자료/Traffic_entropy_final.ipynb   # 이동격차지수 산출
python src/04_drt_simulation/gyeonggi_reallocation.py            # 경기도 DRT 재배치 시뮬레이션
python DRT_반영_이동격차지수_비교_20261010/run_comparison.py      # 현재 vs 재배치 반영 지수 비교
python 이동격차지수_상하위배수_검증_20261011/코드/validation_sido_20pct.py  # 상·하위 배수 검증
```

## 한계

기획 단계에서 검토했던 가구통행실태조사 O/D·생활이동데이터(KTDB·data.molit.go.kr), 온실가스 배출량 데이터, 탄소감축 효과 정량화는 실제로 쓰지 않았습니다. 최종 보고서의 탄소중립 관련 내용은 "DRT가 승용차보다 인원당 배출량이 낮다"는 정성적 서술에 그치며, 별도의 배출량 계산은 수행하지 않았습니다.
