# 데이터 안내

원본 데이터는 용량과 재배포 제약(일부는 이용 신청·승인 필요) 때문에 이 저장소에 직접 포함하지 않습니다. `data/raw/`는 비워둔 채 `.gitignore`로 제외되어 있으며, 아래 절차대로 각자 내려받아 채워 넣으면 `src/` 스크립트가 그대로 동작하도록 경로를 맞춰두었습니다.

| 데이터셋 | 제공처 | 접근 방법 | 비고 |
|---|---|---|---|
| 농림어업총조사 마을조사표 | 통계청 KOSIS / MDIS | KOSIS 공개 통계 또는 MDIS 마이크로데이터 신청 | 5년 주기 (2015, 2020, 2025 공표 확인 필요) |
| 인구총조사 (고령인구·1인가구 비율) | 통계청 KOSIS | 공개 다운로드 | 읍면동 단위 |
| 수치표고모델(DEM) — GEDTM30 | OpenGeoHub Foundation (DOI: 10.5281/zenodo.14900180) | globaldemportal.github.io에서 클립 다운로드 (Type=DTM, Source=글로벌 앙상블 ML 지형) | 맨땅 기준 30m DTM, 로그인·API키 불필요 |
| 읍면동 행정경계 | vuski/admdongkor (admdongkor.vw-lab.com) | 공개 다운로드 (GeoJSON, EPSG:4326, 읍면동 단위) | 경사도 zonal statistics의 폴리곤 레이어로 사용 |
| 의료시설 소요시간별 행정리 수 | 통계청 KOSIS(농림어업총조사 지역조사) | KOSIS 공개 통계 | 교통 데이터와 같은 표 계열, 읍면동까지 조회 가능 |
| 병원정보서비스(전국 병·의원 위경도) | 건강보험심사평가원(공공데이터포털) | data.go.kr 활용신청 후 API/CSV | 활용신청은 보통 즉시 승인, 시도명 컬럼으로 서울 제외 필터링 |

## 폴더 구조

- `raw/` : 위 표의 원본 파일을 그대로 저장
- `processed/` : `src/02_preprocess`, `src/03_index` 실행 후 생성되는 정제·지표 데이터셋

두 폴더 모두 **주제별 하위폴더**(`medical/`, `terrain/` 등)로 나눠서 저장합니다 — 지표가 늘어날수록 어떤 파일이 어느 축(의료접근성, 지형장벽 등)에 속하는지 한눈에 보이도록 하기 위함입니다. 새 지표를 추가할 때도 해당 주제 하위폴더를 만들어 그 안에 원자료·결과를 같이 두세요.

## 행정구역 코드 매칭 주의사항

통계청 행정동 코드, 국토부 KTDB 존 코드, 도로명주소 법정동 코드가 서로 다릅니다. `src/02_preprocess/`에 매핑 스크립트를 두고, 사용한 매핑표의 출처(KTDB 자료실 등)를 스크립트 상단 주석에 명시합니다.
