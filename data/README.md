# 데이터 안내

원본 데이터는 용량과 재배포 제약(일부는 이용 신청·승인 필요) 때문에 이 저장소에 직접 포함하지 않습니다. `data/raw/`는 비워둔 채 `.gitignore`로 제외되어 있으며, 아래 절차대로 각자 내려받아 채워 넣으면 `src/` 스크립트가 그대로 동작하도록 경로를 맞춰두었습니다.

| 데이터셋 | 제공처 | 접근 방법 | 비고 |
|---|---|---|---|
| 농림어업총조사 마을조사표 | 통계청 KOSIS / MDIS | KOSIS 공개 통계 또는 MDIS 마이크로데이터 신청 | 5년 주기 (2015, 2020, 2025 공표 확인 필요) |
| 가구통행실태조사 O/D | 국가교통DB(KTDB, ktdb.go.kr) | 회원가입 후 자료실 신청 | 존(zone) 코드 기준, 행정동 매핑표 별도 제공 |
| 생활이동데이터 | data.molit.go.kr / 서울 열린데이터광장 | 이용 신청 필요할 수 있음 | 통신 3사 기반, 소규모 마을은 비식별 마스킹 존재 |
| 인구총조사 (고령인구·1인가구 비율) | 통계청 KOSIS | 공개 다운로드 | 읍면동 단위 |
| 수치표고모델(DEM) / 경사도 | 국토지리정보원, 국가공간정보포털 | 공개 다운로드 | GIS 전처리 필요 |
| 지역별·차종별 도로부문 온실가스 배출량 | 한국교통안전공단(공공데이터포털) | 공개 다운로드 | 2023.12.31 기준 |

## 폴더 구조

- `raw/` : 위 표의 원본 파일을 그대로 저장 (git 미포함)
- `processed/` : `src/02_preprocess`, `src/03_index` 실행 후 생성되는 정제·지표 데이터셋 (git 포함)

## 행정구역 코드 매칭 주의사항

통계청 행정동 코드, 국토부 KTDB 존 코드, 도로명주소 법정동 코드가 서로 다릅니다. `src/02_preprocess/`에 매핑 스크립트를 두고, 사용한 매핑표의 출처(KTDB 자료실 등)를 스크립트 상단 주석에 명시합니다.
