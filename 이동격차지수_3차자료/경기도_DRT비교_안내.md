# 경기도 이동격차 순위 × 똑버스 운행현황

`Traffic_entropy_final_경기도_DRT비교.ipynb`의 8번을 기존 최종 노트북 실행 직후 실행한다. 기존 Colab 세션에 `eupmyeon_master`가 있으면 추가된 비교 코드 셀만 복사해 실행할 수 있다. 원본 노트북은 변경하지 않았다.

## 비교 기준

- 전국 기준 가중치와 정규화 점수를 유지하고 경기도를 추출한다.
- 시군명과 CSV에 명시된 읍면동 명칭으로 대조한다.
- `은현·남면`은 은현면·남면, `남사·이동읍`은 남사읍·이동읍, `광교1·2동`은 광교1동·광교2동으로 확장한다.
- 신도시, 지구, 리, 법정동과 행정동의 관계는 추정하지 않는다. 따라서 명시 확인 비율은 보수적이며, 나머지를 미운행 지역으로 해석하면 안 된다.
- 운행구역에 명칭이 있다는 것은 해당 읍면동 전체를 운행한다는 뜻이 아니다.
- 제공 CSV의 운행 기록과 비교하며 최신 운행 유지 여부는 별도 검증하지 않았다. 탑승실적은 없어 실제 주민 이용 여부를 판단할 수 없다.
- 결측 포함 지역은 표시하고, 결측 없는 지역만의 순위와 요약도 함께 제공한다. 입력값과 전국 가중치에 남은 한계는 유지된다.

## 생성되는 파일

1. `경기도_이동격차순위_DRT대조.csv`: 경기도 전체 잠정 순위, 변수, 결측/대체 표시, 운행 대조 근거
2. `경기도_상위20_DRT대조.csv`: 상위 20개 지역
3. `경기도_상위권_DRT요약.csv`: 상위 10/20/50개 명시 운행 확인 비율

상위 N은 정렬 후 N행 기준이다. 동일 점수가 경계에 있으면 동점 전체가 포함되지는 않는다.

## 로컬 재현에 필요한 자료 확인 (다운로드 후 갱신)

- 자동차 원자료 발견: `../traffic/1인당_자동차_등록대수_시도_시_군_구__20260923121149.csv` (traffic-contest 기준 형제 폴더)
- 최종 노트북이 사용한 `101_DT_1IN1503_20261004030052.xls`를 `data/`에서 확인해 로컬 재계산을 완료했다.
- traffic의 `101_DT_1IN1503_20260921124932.xls`를 최종 노트북의 읍면동 파서로 읽으면 0행이다. 대체 사용하지 않았다.
- traffic의 인구 CSV는 시군구 열이 없으므로 이름이 같은 읍면동을 안전하게 연결할 수 없다. 대체 사용하지 않았다.
- 실제 경기도 순위·확인 비율은 `gyeonggi_drt_comparison/`에 저장했다. `run_gyeonggi_drt.py`로 재현할 수 있다. 상위 20개 중 명시 운행 확인은 5개(25%)다.

비교용 노트북은 제공 CSV 내용을 포함하므로 Colab에서 운행현황을 다시 업로드하지 않아도 된다. 자료를 갱신하면 `build_drt_notebook.py`를 다시 실행해 반영한다.
