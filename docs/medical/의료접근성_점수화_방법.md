# 의료접근성 취약점수 — 점수화 방법

원자료: KOSIS 농림어업총조사 지역조사 「의료시설 소재지 및 소요시간별 행정리 수」(2020년 기준, 읍/면 단위)
코드: `src/02_preprocess/medical_access_score.py`
결과: `data/processed/medical/medical_access_score.csv` (전국 1,404개 읍/면)

## 1. 원자료 구조

읍/면 하나마다, 시설 종류별로 "그 읍/면 안의 행정리(마을)들이 각 소요시간 구간에 몇 개씩 속하는지"를 센 집계표.

```
행정리내 → 읍·면내 → 읍면외_10분미만 → 10~19분 → 20~29분 → 30~39분 → 40~49분 → 50~59분 → 60분이상
```

## 2. 구간별 대표값(분) 매핑

| 구간 | 대표값(분) |
|---|---|
| 행정리내 | 0 |
| 읍면내 | 7 (표에 정확한 분 단위가 없어 10분미만과 행정리내 사이로 가정) |
| 읍면외 10분미만 | 8 |
| 10~19분 | 15 |
| 20~29분 | 25 |
| 30~39분 | 35 |
| 40~49분 | 45 |
| 50~59분 | 55 |
| 60분이상 | 70 (open-ended 구간이라 보수적으로 근사) |

## 3. 읍/면별 가중평균 소요시간

```
평균소요분 = Σ(구간 대표값 × 그 구간 행정리 수) / 총행정리수
```

마을 하나하나의 실측값이 아니라, 그 읍/면 안에서 "평균적으로 얼마나 걸리는가"를 근사한 값이다.

## 4. 시설을 1차/2차로 분류 (의료법 제3조 기준)

"수술·중증 치료가 중심이냐"로 나눈다 — 종합병원만 법적으로 100병상 이상 + 필수 진료과목별 전속전문의를 요구하는 유일한 등급이기 때문이다.

- **1차(동네의료)**: 약국, 보건진료소, 보건소(지소포함), 일반병·의원, 한방병·의원, 치과병·의원
  일반병원(30~99병상)은 입원은 가능해도 종합병원 같은 필수과목·중증 요건이 없어 시골에서는 사실상 "입원 가능한 동네 의원" 역할을 한다. 한방병원·치과병원도 수술·중증 중심이 아니라는 점은 동일. KOSIS 원자료 자체도 종합병원만 별도 컬럼으로 떼어놨다는 점이 이 구분과 일치한다.
- **2차(대형병원)**: 종합병원만

## 5. 최종 점수

1. 1차 6종의 가중평균 소요시간을 단순평균 → `1차의료_평균소요분`
2. 2차(종합병원)의 가중평균 소요시간 → `2차의료_평균소요분`
3. 각각 min-max 정규화(0~1) → `1차의료_취약점수` / `2차의료_취약점수` (1에 가까울수록 접근성 나쁨 — 기존 이동격차지수와 점수 방향 동일)

## 6. 보조지표

`{시설}_20분이상비율` = 20분 이상 걸리는 행정리 비율. 평균값이 완화시켜버리는 "많이 늦는 소수"를 별도로 보여주기 위한 지표.

## 7. 기준을 바꾸고 싶다면

`medical_access_score.py` 상단의 `BUCKET_MINUTES`(구간 대표값), `TIER1_CLEAR`/`TIER2_CLEAR`(1차/2차 분류) 두 곳만 수정하면 전체 점수가 자동으로 재계산된다.
